# 점진적 SRT와 전사 재개 사양

## 문제

긴 영상은 본 전사와 저신뢰 재시도에 수십 분이 걸린다. 현재는 모든 단계가 끝난 뒤에만 SRT를 만들기 때문에 중간 실패 시 확인할 수 있는 자막이 없고, 재실행하면 이미 끝낸 전사까지 반복한다.

## 사용자 동작

- SRT 출력은 음성 조각을 최대 32개씩 전사한다.
- 배치 하나가 끝날 때마다 최종 출력 옆의 `<이름>.partial.srt`를 원본 타임라인 기준으로 원자적으로 갱신한다.
- 같은 시점에 출력 폴더의 `.<이름>.srt.whisper-local-checkpoint.json`에 앱 전용 체크포인트를 원자적으로 저장한다. 체크포인트에는 입력·모델·실행 도구 식별 정보, 미디어 길이, 음성 조각 경계, 현재 단계, 완료 위치, 원시 자막 데이터가 포함된다.
- VAD가 끝나는 즉시 조각 경계를 체크포인트에 저장한다. 실행이 중단되면 partial SRT와 마지막으로 완전히 저장된 체크포인트를 보존한다.
- 같은 명령을 다시 실행하면 입력과 전사 환경이 일치하는 체크포인트를 자동으로 사용한다. 정규화 오디오는 다시 추출하지만, 완료된 VAD와 Whisper 배치는 반복하지 않는다.
- 재개 시 현재 partial SRT를 즉시 다시 렌더링하므로 교정 사전 변경도 반영한다.
- 저신뢰 재시도도 완료 위치와 선택 결과를 저장해 중단 후 이어간다.
- 최종 SRT 저장에 성공하면 partial SRT와 체크포인트를 제거한다. 정리만 실패하면 최종 SRT 성공은 유지하고 경고를 표시한다.

## 정확성과 안전성

- partial SRT는 아직 처리하지 않은 뒤쪽 발화와 저신뢰 재시도 결과가 빠진 임시 결과다. 매 저장 때 누적 원시 자막 전체를 다시 정리하고 렌더링한다.
- 체크포인트는 스키마 버전, 입력 파일, Whisper 모델, VAD 모델, `whisper-cli`, FFmpeg, FFprobe, 언어와 파이프라인 설정이 모두 일치할 때만 사용한다.
- 환경이 다른 체크포인트는 사용하지 않고 새 전사를 시작한다. JSON이 손상된 체크포인트는 경로를 포함한 오류로 중단하고 기존 partial SRT와 체크포인트를 보존한다.
- partial SRT를 먼저 저장하고 체크포인트를 나중에 저장한다. 두 저장 사이에 중단되면 마지막 배치 하나만 다시 처리한다.
- 최종 출력의 기존 파일 보호와 `-force` 동작은 유지한다.

## 범위

- 점진적 저장과 재개는 `-format srt`에만 적용한다.
- TXT와 VTT는 현재 단일 전사 호출과 최종 저장 동작을 유지한다.
- 배치 크기는 32개로 고정한다. 새 CLI 옵션은 추가하지 않는다.
- 정규화 오디오와 WAV 조각은 장기 보존하지 않는다.
