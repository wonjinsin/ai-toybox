# ADR 0001: 최고 품질 단일 자막 파이프라인

- 상태: 채택
- 결정일: 2026-08-15

## 맥락

긴 무음과 음악이 섞인 영상을 `whisper-cli` 한 번으로 전사하면 VAD가 압축한 시간축과 원본 시간축이 달라질 수 있다. 압축된 SRT의 일부 시작 시간만 후처리로 보정하면 영상 후반으로 갈수록 자막이 실제 발화보다 수십 초에서 수분 일찍 나오는 누적 오차가 발생했다.

원시 SRT 후처리만으로는 토큰 신뢰도를 이용할 수 없고, 무음·음악에서 생성된 반복 환각과 긴 한 줄 자막을 안정적으로 제거하기 어렵다. 사용자는 속도 모드가 아닌 최고 품질 결과 하나만 원한다.

## 결정

다음 단일 파이프라인을 항상 사용한다.

1. FFmpeg로 전체 오디오를 16kHz 모노 PCM으로 변환하고 동적 음량 정규화를 적용한다.
2. 정규화 WAV를 15초 단위로 나누고 전용 `whisper-vad-speech-segments`를 최대 4개씩 실행한다. 각 조각에서 Silero VAD v6.2.0의 순환 상태를 초기화하고 탐지 결과를 원본 타임라인으로 복원한다.
3. 발화 사이 최대 3초의 대화 중 멈춤을 문맥으로 보존하고, 발화 구간을 경계 여유 150ms가 포함된 최대 20초 원본 시간 조각으로 최대 4개씩 병렬 생성한다.
4. 다국어 `large-v3` 모델을 로드한 `whisper-cli` 다중 파일 실행과 beam size 1로 조각의 전체 JSON을 생성한다. SRT는 재개 가능한 최대 128개 배치, TXT와 VTT는 전체 조각 단위로 실행한다.
5. JSON 세그먼트 시간에 조각의 원본 시작 시간을 더해 자막 절대 시간을 복원한다.
6. 저신뢰 구간은 최대 128개씩 beam size 8의 결정적 디코딩으로 재시도하고, 배치 경계마다 SRT 체크포인트를 저장한다.
7. 평균 토큰 확률 0.32 미만과 일본어 비언어 발성을 필터링한다. 일본어 또는 자동 언어 모드에서 `ご視聴ありがとうございました`, `おめでとうございます` 계열의 알려진 일본어 환각 상투문구는 같은 파일에 두 번 이상 나올 때만 모두 제거한다. 한 번만 나온 문구와 `はい`, `うん`, `え`, `（笑）`같은 의미 있는 짧은 응답은 보존한다.
8. 선택적 JSON 교정 사전을 긴 원문부터 적용한다. 코드에 영상별 문구를 하드코딩하지 않는다.
9. 자막당 최대 5.5초, 50ms 최소 간격, 비겹침, 언어별 줄 길이를 적용하고 입력 미디어 길이 초과를 검증한다.

빠른 모드, 균형 모드, 양자화 모델을 선택하는 품질 프로필은 제공하지 않는다. VAD 모델을 찾지 못하면 품질을 낮춘 대체 경로로 실행하지 않고 오류를 반환한다.

## 결과

### 장점

- 긴 무음이 여러 번 나와도 조각별 절대 오프셋을 사용하므로 시간 오차가 누적되지 않는다.
- 토큰 신뢰도와 원본 시간 정보를 함께 사용해 SRT 문자열 후처리보다 정확한 필터링이 가능하다.
- 실제 전사는 다중 파일 배치로 처리해 조각마다 `large-v3`를 다시 로드하지 않는다.
- VAD 탐지에서는 약 3GB의 `large-v3`를 로드하지 않아 긴 파일의 탐지 준비 시간을 줄인다.
- VAD 상태가 15초마다 초기화되므로 앞 구간의 음악·잡음이 뒤의 작은 발화 판정에 누적되는 문제를 줄인다.
- 짧은 발화를 주변 대화와 함께 전사해 `auto` 언어 판정과 화자 전환 문맥이 안정된다.
- 본 전사는 beam size 1로 디코딩 비용을 낮추고, 신뢰도 0.50 미만 구간만 beam size 8로 재시도해 어려운 발화의 품질을 보완한다.
- 저신뢰 재시도도 최대 128개를 묶어 `large-v3` 반복 로딩을 줄인다.
- 알려진 일본어 환각 상투문구를 파일 단위로 집계해 높은 신뢰도로 반복되는 무음·잡음 환각도 제거한다.
- 모드 선택이 없어 CLI와 운영 결과가 단순하고 일관된다.

### 단점

- VAD 스캔과 조각 전사를 분리하므로 정규화 WAV를 한 번 더 읽는다.
- VAD 모델을 조각마다 새 프로세스에 로드하므로 전체 파일을 한 번에 탐지할 때보다 수 초가 추가될 수 있다. 최대 4개 병렬 실행으로 증가 폭을 제한한다.
- 임시 정규화 WAV와 조각 WAV가 필요해 디스크 I/O와 임시 저장 공간이 늘어난다.
- 배치 도중 중단되면 마지막 체크포인트 이후 완료된 조각을 최대 128개까지 다시 전사할 수 있다.
- 0.32 신뢰도 임계값과 비언어 필터는 일부 짧고 불분명한 실제 발화를 제거할 수 있다.
- 실제 대화에서 같은 환각 상투문구를 두 번 이상 말하면 해당 발화도 제거될 수 있다.
- `large-v3`만 사용하므로 양자화 소형 모델보다 실행 시간과 메모리 사용량이 크다.

## 검토한 대안

### `whisper-cli` 내장 SRT와 VAD 로그를 후처리

구현이 간단하지만 압축된 시간축의 누적 오차를 완전히 복원하지 못하고 토큰 신뢰도를 잃어버린다. 기각했다.

### 조각마다 `whisper-cli` 별도 실행

원본 시간은 안전하지만 20초 조각마다 3GB 모델을 로드해 긴 영상에서 실행 비용이 너무 커진다. 다중 파일 한 번 실행으로 대체했다.

### 빠른/균형/고품질 모드

사용자가 최고 품질 하나만 요구했고 낮은 품질 경로는 결과 편차와 테스트 행렬만 늘린다. 기각했다.

### 클라우드 전사 API

로컬 처리와 미디어 비전송이 프로젝트 제약이므로 기각했다.

## 후속 검토

- 신뢰도 임계값과 비언어 필터는 실제 일본어 자막 표본으로 오탐·미탐을 측정해 조정한다.
- 조각 경계의 반복·절단 오류가 보이면 인접 조각 토큰의 시간·문자열 유사도를 사용한 경계 병합을 검토한다.
- 현재 결정을 바꾸려면 시간 정확도, 환각률, 가독성, 실행 시간을 함께 측정한 회귀 표본을 먼저 추가한다.
